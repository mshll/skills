# Toolbox

Techniques for drawing a signature and setting the axes. Each is a means, never a look: two products can share a technique and look nothing alike, because the world, the colour rule and the content differ.

Every entry gives:

- **Encodes**: the quantity, state or meaning it carries.
- **Earned when**: the product condition that justifies it.
- **Build**: what is fixed (what makes the technique) and what varies (what the direction sets).
- **Costume when**: how the same technique turns into decoration.
- **Gold**: `gold/techniques/<slug>.*` files to open.

| File | Holds |
|---|---|
| [data-marks.md](data-marks.md) | Ways to draw a figure, a series or a state: tick bars, dither and halftone fills, dot-matrix cells, hatch, readouts, rulers, barcodes, calendar markers, reframed units, data on photos |
| [colour-and-surface.md](colour-and-surface.md) | Colour strategies with their rules, surface models, grounds, grain, gradients that depict something, button edges |
| [type.md](type.md) | Where a voice face goes, figure typography, mono, numerals, pairings, reflex faces |
| [imagery.md](imagery.md) | Photography, illustration per record, engraved objects, domain objects as containers, mascots with states, generated art, empty-state diagrams |
| [interaction.md](interaction.md) | Signature interactions: morphs, progress in the control, staged sheets, detents, hold to confirm, material-true effects |

The toolbox is open. A signature may use a technique that is not listed; write it up in the same shape and propose it at the Taste step.
